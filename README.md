## Important launch notes

1. The contact form is intentionally static and opens the visitor's default email application with the form details addressed to info@decimaintl.com. Connect it to the company-approved form backend before launch if direct server-side submissions are required.
2. Careers links to Decima International's official Greenhouse job board so openings remain current.
3. Project images and facts are taken from the supplied company profile. The confidentiality disclaimer is retained because some images may be illustrative.
4. Google Poppins is loaded from Google Fonts; the fallback is Montserrat / Arial if external font loading is unavailable.
5. Update canonical URLs and sitemap entries if the production path differs from https://decimaintl.com/.
6. The website is static HTML/CSS/JavaScript and can be uploaded to a normal web host. Future blog and project publishing will be easier with a CMS or static-site build workflow.
