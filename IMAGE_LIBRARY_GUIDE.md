# Decima Website Image Library

The website layout and animation code have not been changed. Only the image library has been reorganized, and all website references have been updated.

## Main replaceable image folders

- `assets/images/branding/` — logos, favicon, and social-sharing cover
- `assets/images/hero/` — homepage hero slides and page-header images
- `assets/images/about/` — company story, mission, and vision images
- `assets/images/services/` — service and sector images
- `assets/images/projects/` — all project, portfolio, and Latest Work photographs
- `assets/images/insights/` — blog and article cover images
- `assets/images/team/` — CEO, COO, and Director of Operations photographs
- `assets/images/partners/` — partner and client logos
- `assets/images/maps/` — interactive map artwork

## Design-support images

- `assets/images/ui/decorative/` — shapes used by animations and section decoration
- `assets/images/ui/template-support/` — legacy template graphics required by the theme CSS. These are not the main content photographs and normally should not be replaced.

## Safest replacement method

1. Prepare the replacement image in the same dimensions and format.
2. Give it exactly the same filename as the existing image.
3. Replace the existing file inside the appropriate folder.
4. Refresh the browser with `Ctrl + F5`.
