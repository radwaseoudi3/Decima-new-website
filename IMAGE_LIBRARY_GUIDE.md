# Decima Website Image Library

The active shared image folders are:

- `assets/images/insights/` — one image per Insight, reused on every Insight card and article location.
- `assets/images/latest-work/` — one image per project, reused on every Latest Work card, project listing, related card, and project detail page.
- `assets/images/shared/branding/` — logos, favicon, and social-sharing image.
- `assets/images/pages/` — page-specific headers and images that are not shared between Insights or Latest Work.

To update a shared image, overwrite the existing file with a new WebP file using exactly the same filename. No HTML editing is required.

The alternative-fuels machinery image in both centralized folders has been edited to remove the CAT logo.
