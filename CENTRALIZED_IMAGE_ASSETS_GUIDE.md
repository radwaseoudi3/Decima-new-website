# Centralized Image Assets

The website now uses one editable image file everywhere each Insight or Latest Work project appears.

## Insights

Folder: `assets/images/insights/`

- `insight-ai-ready-data-center-infrastructure.webp`
- `insight-program-governance-complex-capital-programs.webp`
- `insight-alternative-fuels-data-center-transition.webp`

Each file is used on the Home page Insights section, the Insights listing page, its article page, related Insight cards, and the article breadcrumb background. Replace the image while keeping the same filename.

## Latest Work

Folder: `assets/images/latest-work/`

There is one `.webp` file for each project. Each file is used on the Home page Latest Work section, Latest Work and Projects listings, related-work cards, service-page project cards, and the matching project detail page. Replace the image while keeping the same filename.

## Important

1. Keep the existing filename and `.webp` format.
2. Recommended size: 1500 x 950 px for Latest Work and 1200 x 760 px for Insights.
3. Refresh the browser after replacing a file. If the old image remains, clear the browser cache or use Ctrl+F5.
4. The CAT logo was removed from the alternative-fuels machinery image in both centralized folders.
