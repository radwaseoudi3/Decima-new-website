# Project Image Folder Guide

All photographs used by the Projects page, Latest Work page, home-page project gallery, and project-detail pages are stored in:

```text
assets/images/projects/
```

To replace a photograph without editing HTML, export the replacement as WebP and overwrite the existing file using the same filename.
