# Latest Work Image Folder Guide

All photographs used by the Home page Latest Work section, Latest Work page, Projects page, related-work cards, service-page project cards, and project-detail pages are stored in:

`assets/images/latest-work/`

There is one WebP file per project. Replace a file using the same filename and the new image will appear everywhere that project is displayed.

Recommended format: landscape WebP, approximately 1500 × 950 px.
